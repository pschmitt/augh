# aughhhh

An unapologetically loud Android sign maker. Type a message, tune its vibe, and put it on
full-screen display mode when the moment arrives.

## Development

```sh
./gradlew ktfmtCheck
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

The debug application id is `dev.pschmitt.aughhhh.debug`.
